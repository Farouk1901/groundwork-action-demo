# Groundwork Action demo

Open a ticket here, written as if it were a ticket for [honojs/hono](https://github.com/honojs/hono). The
[Groundwork](https://github.com/Farouk1901/groundwork) Action answers with the files it will most likely touch, who
knows that code and what to watch, from how similar hono tickets were fixed, in a Relate graph built on the runner.

The workflow is [`.github/workflows/groundwork.yml`](.github/workflows/groundwork.yml): add the same few lines to
any repository.
